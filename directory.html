ข้อมูลบุคลากร

สายบังคับบัญชาในหน้านี้คือสิ่งที่ระบบใช้กำหนดผู้อนุมัติ เมื่อมีผู้ส่งเรื่อง ระบบจะหาผู้บังคับบัญชาของเจ้าของเนื้อหาจากข้อมูลนี้ การแก้ไขที่นี่มีผลกับรายการที่ส่งเข้ามาใหม่ทันที ส่วนรายการที่ส่งไปแล้วและติดค้างอยู่เพราะยังไม่มีผู้อนุมัติ จะเดินต่อได้เมื่อผู้ดูแลระบบฐานข้อมูลความรู้กดปล่อยรายการ หรือกำหนดผู้อนุมัติใหม่ในหน้า “งานที่ต้องดำเนินการ” ซึ่งจะอ่านข้อมูลบุคลากรที่แก้ไขแล้วนี้

หมายเหตุ: ช่อง “ไม่มีผู้บังคับบัญชาเหนือขึ้นไป” และ “ยกเว้นการอนุมัติและการตรวจเนื้อหา” มีผลทันที ผู้ที่ได้รับการยกเว้นจะส่งเรื่องแล้วเผยแพร่ทันทีโดยไม่ต้องผ่านการอนุมัติ และไม่ต้องมีผู้ตรวจเนื้อหา ส่วนช่องแรกจะลดจำนวนขั้นการอนุมัติ เมื่อไม่มีผู้บังคับบัญชาเหนือขึ้นไปแล้ว

ทุกคนที่ปฏิบัติงานอยู่มีผู้บังคับบัญชาที่ใช้งานได้แล้ว

รายชื่อที่ได้รับการยกเว้นการอนุมัติ

ยังไม่มีผู้ใดได้รับการยกเว้น

รายชื่อทั้งหมด (11 คน)

ชื่อรหัสพนักงานหน่วยงาน ผู้บังคับบัญชาสถานะการปฏิบัติงานยกเว้นการอนุมัติ
คณะผู้บริหารระดับสูง (กลุ่มผู้ใช้งาน) — — — ปฏิบัติงานอยู่ —
กมลชนก แสงทอง CR000734 องค์กรและกลยุทธ์ ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
ชนิดา บริการดี CS007251 บริการลูกค้า ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
ณัฐวุฒิ พงษ์ไพบูลย์ CR000108 องค์กรและกลยุทธ์ ไม่มีผู้บังคับบัญชาเหนือขึ้นไป ปฏิบัติงานอยู่ —
ธนพล ศรีวิไล RL002047 ความเสี่ยง กฎหมาย และกำกับดูแล ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
ประเสริฐ กิจเจริญ SF005562 ความปลอดภัย ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
พิมพ์ใจ รักงาน OP006475 ปฏิบัติการและบำรุงรักษา ณัฐวุฒิ พงษ์ไพบูลย์ ไม่ได้ปฏิบัติงานแล้ว —
วิภาดา มีสุข TC001196 เทคโนโลยีและข้อมูล ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
สมชาย ใจดี HR004821 ทรัพยากรบุคคล ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
สุริยา ก้าวหน้า PS002988 จัดซื้อและห่วงโซ่อุปทาน อรุณี ทองแท้ ปฏิบัติงานอยู่ —
อรุณี ทองแท้ FN003310 การเงินและบัญชี ณัฐวุฒิ พงษ์ไพบูลย์ ปฏิบัติงานอยู่ —
